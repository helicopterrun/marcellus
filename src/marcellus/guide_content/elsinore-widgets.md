## Home-screen widgets

- **Recent Events** (small/medium/large) — the latest detections with
  thumbnails; tap one to open its event in the app.
- **System Status** — Frigate health, current activity, and a storage bar
  at a glance.

Add them from the home screen's widget gallery; they refresh on iOS's
widget schedule and use the same theme palette as the app.

## Live Activities

When a situation is unfolding — someone approaching the house, a visit in
progress — Elsinore can start a **Live Activity**: a live card on the lock
screen and in the Dynamic Island showing an elapsed timer, direction chip,
the zone ladder as it's climbed, and an approach trace. It updates in real
time as the sidecar's push engine escalates or resolves the situation, and
its action buttons work without unlocking the phone.

Enable and tune Live Activities in Settings → Alerts → Live Activities.
They're delivered via the same push pipeline —
[Replay](/replay) scenarios will trigger them, which is the easiest way to
see one without waiting for a visitor.
